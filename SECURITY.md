# Security

If you discover a security vulnerability please report it following these guidelines:

1. Open a private security issue in this repository (Use "Create new issue" -> "Security" if available).
2. Or email the maintainers at: security@quincyjisah.dev

We will respond within 72 hours.

Notes:
- Do not include exploit code in public issues. Use a private report or email.
- For third-party audits or disclosures, contact the maintainers first to coordinate.
